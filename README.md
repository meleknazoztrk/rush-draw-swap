# ⚡ Rush Draw Swap (Gartic Phone Modu)

Arkadaşlarınızla oynayabileceğiniz, 15 saniyelik eşli çizim ve tahmin oyunu.

## 🎮 Özellikler

- 🔑 **Özel Oda & Kod Sistemi:** 4 haneli kodla sadece arkadaşlarınızın girebileceği özel odalar.
- 🎭 **Gartic Phone Modu:** Tahminler hemen ifşa edilmez; tur sonunda tüm çizimler ve tahminler sergilenir.
- ⏱️ **Tur & Süre Ayarı:** Oda kurucusu tur sayısını (1, 3, 5) ve çizim süresini (15s, 20s, 30s) seçebilir.
- 🎨 **Gelişmiş Çizim Tuvali:** Renk paleti, kalem kalınlıkları ve silgi.
- 🏆 **Puanlama & Podyum:** Doğru tahminlere ve çizimi anlaşılan çizerlere puan; oyun sonu şampiyon podyumu.
- 👥 **Esnek Oyuncu Sayısı:** Dairesel takas (Ring Swap) sayesinde 2, 3, 4, 5+ kişi oynayabilir.
- 🌐 **Dünya Çapında Erişim:** Cloudflare Tunnel entegrasyonu ile dünyanın her yerinden arkadaşlarınızla oynama imkanı.

## 🚀 Kurulum & Çalıştırma

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Sunucuyu başlatın:
```bash
node server.js
```

3. Tarayıcınızda açın:
```
http://localhost:3000
```
